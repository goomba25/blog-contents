# RAII

RAII는 `Resource Acquisition Is Initialization`의 약자로 C++의 특성을 활용한 자원 관리 패턴입니다.

일반적으로 싱글톤과 같은 "디자인 패턴"이라고 부르기에는 좀 성격이 다르지만,   
어쩄건 C++를 하는 입장에서는 중요한 설계 패턴이기 떄문에 디자인 패턴 카테고리에 분류했습니다.

### GC의 부재

요즘 거의 모든 언어는 자체적으로 GC(Garbage Collector)를 제공하고 있지만,    
C와 C++는 개발자가 '직접' 메모리의 해제를 신경써줘야 합니다.   
그러다보니 개발자가 실수로 메모리를 해제하지 않고 계속 사용하다보면 "메모리 누수(Memory Leak)"가 발생하게 됩니다.

그래서 등장한 설계 패턴이 RAII입니다.   
RAII는 간단하게 설명해서 "할당된 메모리를 자동으로 해제하도록 설계"합니다.

이러한 RAII 패턴을 사용한 대표적인 클래스는
`std::lock_quard`, `std::unique_ptr`, `std::shared_ptr` 등이 있다고 합니다.   
(사실 엥간한? STL은 RAII 기반이라고 합니다.)

## RAII 기본 형태

```cpp
class TestClass {
  public:
    TestClass() {
        할당;
    }

    ~TestClass() {
        해제;
    }
};
```

사실 RAII는 기본 형태? 라고 부를만한 특정 형태는 없습니다.   
다만 자원이 할당되면 반드시 해제될 수 있도록 `생성자/소멸자`를 활용하는 것이 핵심입니다.

* 이는 객체의 생명 주기와 내부 자원의 생명 주기를 강제로 맞추게 됩니다.

## RAII 특징

이러한 RAII 설계 방식은 여러 장점이 있습니다.

우선 예외 상황이 발생하더라도 소멸자가 호출되면서 자원이 해제됩니다.   
메모리 누수를 방지하고, 예외 상황에 대한 안정성을 높일 수 있습니다.

또한 클래스 내부에서 자원을 할당 및 해제하기 때문에 코드가 조금 더 깔끔하고 간결해질 수 있습니다.
